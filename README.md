# Price Calculator Web App

## Overview
A practical web application that dynamically calculates prices for Herbalife products.  
This project focuses on real-world usability and logical computation in the browser.

---

## Features
- Dynamic price calculation
- Instant result updates
- Clean and minimal interface

---

## Technologies Used
- HTML
- CSS
- JavaScript

---

## Learning Outcomes
- JavaScript logic building
- Real-time data handling
- Practical problem-solving
- UI/UX clarity and responsiveness
